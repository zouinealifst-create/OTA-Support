# OTA Support — Audio Recordings

This folder stores audio recordings captured during voice calls between users and OTA Support.

## Format
- Files are saved as `.mp3` (browser MediaRecorder format)
- Filename pattern: `ota-call-audio-<timestamp>.mp3`
- Audio is downloaded automatically to your browser's download folder when a call ends

## Note
Audio recording requires microphone permission in your browser.
If permission is denied, calls will still work — only the text transcript will be saved.
