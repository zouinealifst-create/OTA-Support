# OTA Support — Session Reports

This folder stores conversation reports generated at the end of each session.

## Types of Reports

### Chat Reports
- Exported via the ↓ button in the top bar
- Filename: `ota-chat-report-<timestamp>.txt`
- Contains: full conversation transcript, session stats, rating

### Call Reports
- Auto-downloaded when a call ends
- Filename: `ota-call-report-<timestamp>.txt`
- Contains: call duration, live transcript, agent name

## Format
All reports are plain `.txt` files and can be opened in any text editor.
They are downloaded directly to your browser's Downloads folder.
